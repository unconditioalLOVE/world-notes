# WORLD NOTES

自分専用のインタラクティブな世界地図帳。

地理・世界史の知識を地図上に蓄積できるシンプルなアプリです。

## 特徴

- 正確な世界各国の国境線（Natural Earth 1:110m）
- 国クリックでメモパネル（日本語・英語国名対応）
- 都市メモの登録
- 主要河川の常時表示
- 地図上への直接描画（フリーハンド・消しゴム・色・太さ）
- 複数レイヤー管理（表示/非表示・独立保存）
- LocalStorageによる自動保存
- PC・スマートフォン対応（ピンチズーム・タッチ描画）

## 使い方

1. 国をクリック → 右側（モバイルは下部）にメモパネルが開く
2. ✏️ ボタンで描画モードON
3. 📚 でレイヤー一覧を開く
4. 描画内容・メモは自動でブラウザに保存されます

## 技術

- 純粋な HTML / CSS / JavaScript
- D3.js（地図投影・パス生成）
- GeoJSON（Natural Earth）
- LocalStorage

GitHub Pages でそのまま公開可能です。
